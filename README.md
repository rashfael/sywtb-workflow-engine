# So You Want To Build A Workflow Engine

Head over to the [doc book](https://docs.sywtb-workflow-engine.rash.codes) to start reading about my experiences building low-code platforms and how I would approach them now.


## Writing / Deploying Docs

```sh
npm run docs:dev
npm run docs:build
npm run docs:deploy
```


## Requirements

- latest Node.js (v25+)
- latest Docker

## Running the dev env

```sh
npm ci
npm run dev
```
